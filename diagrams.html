Talking to the model (Part 4)

flowchart TD
    U[User types a question] --> EMB[Embed with\nall-MiniLM-L6-v2]
    EMB --> Q[Query FAISS IndexIVFFlat:\ntop k=20, recall oriented]
    Q --> RR[Rerank k candidates with\ncross-encoder/ms-marco-MiniLM-L-6-v2\nagainst actual query text]
    RR --> TH{Anything clear\nthe rerank score?}
    TH -- no --> NC[No match template:\nContext: none]
    TH -- yes --> CTX[Context template:\ntop reranked text,\ntruncated to block_size]
    NC --> GEN[model.generate\nfrom model.py, reused as is]
    CTX --> GEN
    GEN --> DEC[Decode tokens back to text]
    DEC --> PARSE{Matches\nCALL: tool_name args\npattern?}
    PARSE -- no --> OUT[Print the answer]
    PARSE -- yes --> LOOKUP[Look up tool_name in\nsmall dict registry, tools.py]
    LOOKUP --> RUN[Call the tool,\ncatch any exception]
    RUN --> OUT2[Append result,\nprint or feed back for\none more generate pass]
    OUT --> U
    OUT2 --> U

What's hand-rolled vs swiped/library-backed

Every piece checked against the project's own minimal-hand-rolling rule before being written: does this already exist in the project, the stdlib, an installed dependency, GitHub, or StackOverflow first (swiper's job on every real build), and only composed by hand when nothing did. Green = cloned from a real reference or entirely done by an installed library. Yellow = original glue code, because no existing thing did this specific composition (confirmed by swiper's own search, not assumed).

Pipeline

flowchart TD
    A[Clone karpathy/nanoGPT into model/] --> B[Smoke test:\nshakespeare_char prepare.py\n+ CPU/GPU train.py]
    B --> C[Prepare real dataset:\ndata/openwebtext/prepare.py]
    C --> D[Scale config to 12GB VRAM:\nreduce n_layer/n_embd/block_size,\nbatch_size + grad_accum to fit,\ncompile=True on Linux/WSL]
    D --> E[Train from scratch:\npython train.py config/train_gpt2_local.py]
    E --> F[Checkpoint + eval loss\nevery eval_interval]
    F --> P{Want to game?}
    P -- yes --> Q[pause_training.sh:\nCtrl+C, VRAM freed]
    Q --> R[resume_training.sh:\n--init_from=resume]
    R --> E
    P -- no --> G{Loss still improving\nand within week budget?}
    G -- yes --> E
    G -- no --> H[Sample from model:\npython sample.py --out_dir=...]
    H --> I[Base model trained\nfrom scratch]

    J[Download Wikipedia summaries:\nabokbot/wikipedia-first-paragraph]
    J --> J2[Build tool corpus in\ntoolstore/corpus/tool_examples/]
    J2 --> K[embed.py: sentence-transformers\nall-MiniLM-L6-v2, runs on CPU\nin parallel with GPU training]
    K --> L[build_index.py: write fact + tool\nrows into shared sqlite-vec store]
    L --> L2[build_faiss_index.py: migrate\nembeddings into FAISS IndexIVFFlat,\nsqlite-vec brute force too slow at scale]

    L2 --> S[build_sft_dataset.py:\nRAG + tool call templates\nfrom the vector store]
    I --> T[train_sft.py: short fine tune\non templated examples]
    S --> T
    T --> M[toolstore/chat.py: query.py\nretrieves top k at inference time]
    M --> N[Model conditioned to\nanswer from context and call tools]
